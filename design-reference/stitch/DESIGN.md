## Brand & Style

This design system expresses a bright, ultra-modern intersection of next-generation travel telecommunications and decentralized fintech. Built around real-time connectivity, dynamic telemetry, and micro-billing, the visual identity pairs the precision of an aerospace cockpit with the effortless warmth of modern consumer software.

The target audience encompasses digital nomads, international business travelers, crypto-native explorers, and tech-forward tourists who demand transparent, pay-as-you-go cellular data without opaque roaming charges.

The aesthetic is characterized by:
- **Luminous Precision:** Clean, warm off-white canvas backgrounds punctuated by high-contrast primary typography and sharp structural cards.
- **Electric Accents:** Energetic violet sparks juxtaposed with telemetry teal and active protocol indicators (emerald active nodes and stellar amber alerts).
- **Tactile Softness:** Fully rounded pill shapes for primary actions and status chips counterbalanced by structured, gently radiused data containers.
- **Glass & Diffusion:** High-clarity ambient depth, gossamer borders, and frosted telemetry overlays that evoke airborne instrumentation.

## Colors

The palette is engineered to achieve immediate clarity in daylight conditions while feeling energetic, tech-forward, and premium.

### Primary Spectrum (Electric Violet)
- **Primary Main (`#6941FF`):** Used for key interactive triggers, hero gradient emphasis, high-value accents, and focused active components.
- **Primary Hover / Deep (`#5A32F4`):** Pressed and focused states for primary buttons and high-priority interactive telemetry.
- **Primary Subtle / Wash (`#EEE9FF`):** Badge backdrops, active sidebar selections, and tinted container accents.

### Secondary & Functional Spectrum (Telemetry & Network Health)
- **Telemetry Teal (`#008C99`):** Represents live data streams, connection pipelines, and real-time connectivity indicators.
- **Teal Light Wash (`#E5F7F8`):** Data metrics background fill and connectivity sub-panels.
- **Active Node Green (`#31C48D`):** Live telemetry indicators, confirmed Soroban smart contract micropayments, and positive ledger balances.
- **Stellar Alert Amber (`#FDDA24`):** Protocol indicators, testnet warnings, and fuel reserve notifications.

### Neutral & Surface Hierarchy
- **Canvas Base (`#FAF9F7`):** Warm, tactile atmospheric off-white background that eliminates clinical glare.
- **Surface Elevation / Pure White (`#FFFFFF`):** Floated card surfaces, active cockpits, tooltips, and flyouts.
- **Card Subtle Fill (`#F4F3F0`):** Secondary nested wells, disabled inputs, and telemetry track beds.
- **Border Crisp (`#E8E5E4`):** Delicate, low-contrast structural outlines grounding cards and dividers.
- **Text Headings / Charcoal Dark (`#19181D`):** High-legibility, near-black ink for headlines and vital data readouts.
- **Text Body / Slate Slate (`#5F5C68`):** Balanced, low-eyestrain tone for descriptive narrative, secondary labels, and flight manifests.
- **Text Muted (`#8E8B97`):** Disabled states, input placeholders, and secondary breadcrumbs.

## Typography

The typographic hierarchy pairs the structured, geometric, technical tone of **Space Grotesk** with the neutral, hyper-legible utility of **Inter**.

- **Space Grotesk** drives all primary brand statements, hero headlines, telemetry numerical values, card titles, and uppercase telemetry trackers (`label-caps`). Its geometric terminals and deliberate technical quirks reinforce high-speed networks, crypto protocols, and satellite routing.
- **Inter** handles continuous reading, body paragraphs, interactive button labels, input placeholders, and explanatory metadata. It keeps reading effortless across dense tables and mobile viewports.
- **Caps Hierarchy:** System telemetry tags, network status strings, and category super-headers must always be rendered in `label-caps` with uppercase transformation and `0.08em` tracking.

## Layout & Spacing

The layout model is anchored on an intentional, highly organized 12-column grid on desktop displays and a unified single-to-two column fluid stack on mobile devices.

### Grid Architecture
- **Desktop (>= 1200px):** 12-column fluid grid, `1.5rem` (`24px`) gutters, maximum container width of `1280px` centered with dynamic canvas margins. In Cockpit/Dashboard mode, an asymmetric structure is used: fixed `260px` vertical telemetry sidebar alongside a flexible 10-column dynamic workspace.
- **Tablet (768px – 1199px):** 8-column layout with `1.25rem` gutters and `2rem` side margins. The cockpit sidebar collapses into an accessible top command bar or drawer.
- **Mobile (< 768px):** 4-column layout, `1rem` gutters, and `1.25rem` canvas edge margins. Multi-column telemetry indicators stack vertically into focused metric cards.

### Spacing Principles
Component padding strictly follows the 4px/8px geometric progression:
- Metric pill tiles use `space-xs` vertical by `space-md` horizontal padding.
- Interactive hero cards utilize `space-xl` to `space-2xl` internal padding to generate breathable visual rhythm.
- Inter-section spacing commands `space-3xl` (`72px`) separation on desktop, shrinking to `space-2xl` (`48px`) on mobile devices.

## Elevation & Depth

Visual depth is achieved through an airy, light-refracting hierarchy that avoids oppressive dropshadows in favor of soft, diffused ambient light and tactile surface transitions.

### Surface Tiers
- **Tier 0 (Backdrop Canvas):** `#FAF9F7`. Matte, non-reflective base plane that warms the interface.
- **Tier 1 (Content Plates & Cards):** `#FFFFFF` paired with an ultra-fine border (`1px solid #E8E5E4`). Floating shadow: `0 4px 20px -2px rgba(25, 24, 29, 0.04), 0 12px 32px -4px rgba(105, 65, 255, 0.03)`.
- **Tier 2 (Interactive Flyouts & Floating Navs):** `#FFFFFF` with glassmorphic backdrop blur (`backdrop-filter: blur(16px)` with 92% opacity) where applicable. Shadow: `0 8px 30px rgba(25, 24, 29, 0.08), 0 2px 6px rgba(105, 65, 255, 0.04)`.
- **Tier 3 (Active Flight Copilot & Real-Time Nodes):** Elevated telemetry panels accented with an outer glow using Primary Violet: `0 16px 48px -8px rgba(105, 65, 255, 0.12)`.
- **Tier Inset (Wells & Progress Beds):** `#F4F3F0` with an inner shadow: `inset 0 1px 2px rgba(25, 24, 29, 0.06)` for progress bars and telemetry indicators.

## Shapes

The shape system employs an intentional contrast between aerodynamic pill elements and structured, balanced containers:

- **Full Pills (`rounded-full` / `9999px`):** Reserved for high-priority interactive components, such as primary action buttons (`Planificar mi viaje`), filter chips, live network tags (`TESTNET LIVE`), navigation bubble links, and switch thumbs.
- **Outer Shell Surfaces & Cards (`rounded-2xl` / `24px` to `28px`):** Large cockpit cards, simulated e-SIM previews, and telemetry widgets feature generous 24px–28px curvatures to appear friendly, modern, and approachable.
- **Nested Metrics Containers (`rounded-xl` / `16px`):** Sub-metrics (fuel gauge, active consumption blocks) maintain nested 16px radii conforming harmoniously within the 24px parent boundary.
- **Micro UI (`rounded-lg` / `8px`):** Data tables, inline code badges, and system checkboxes.
